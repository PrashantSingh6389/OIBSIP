# 🌡️ Temperature Converter Website

## 📌 Project Overview

The Temperature Converter Website is a simple and responsive web application that converts temperature values between Celsius (°C), Fahrenheit (°F), and Kelvin (K).

This project was developed using HTML, CSS, and JavaScript as part of the Oasis Infobyte Web Development & Designing Internship.

---

## 🚀 Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Input validation
- Error message for invalid input
- Absolute Zero validation
- Responsive Design
- Clean and Modern User Interface

## ▶️ How to Run the Project

1. Download or Clone the repository.
2. Open the project folder.
3. Double-click **index.html**
4. Enter a temperature.
5. Select the input unit.
6. Click **Convert**.
7. View the converted temperatures.

## 📖 Temperature Conversion Formula

### Celsius → Fahrenheit

```
°F = (°C × 9/5) + 32
```

### Fahrenheit → Celsius

```
°C = (°F − 32) × 5/9
```

### Celsius → Kelvin

```
K = °C + 273.15
```

### Kelvin → Celsius

```
°C = K − 273.15
```
