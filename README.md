# TechNova Landing Page

## 📖 Description
TechNova is a responsive landing page created using HTML and CSS as part of the Oasis Infobyte Web Development Internship.

## ✨ Features
- Responsive Design
- Sticky Navigation Bar
- Hero Section
- Features Section
- About Section
- Testimonials
- FAQ Section
- Contact Form
- Newsletter Section
- Footer with Social Icons

## 🛠 Technologies Used
- HTML5
- CSS3

## 📁 Project Structure

TechNova/

└── images/
    ├── hero.svg
    └── about.svg

## 🚀 How to Run
1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html` or open it in your web browser.
